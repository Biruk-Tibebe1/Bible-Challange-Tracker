# Bible Books

`bible-data.ts` is the framework-independent structural source of truth for the standard Protestant Bible. It defines all 66 books in canonical order and generates chapter references with a continuous global chapter number.

Use its lookup and range utilities for book/chapter access. `validateBibleDataset()` checks the catalog counts, ordering, unique IDs and chapter numbers, continuity, and required global-number examples. This feature does not depend on challenge dates, schedules, users, persistence, or Bible text.

Amharic Scripture uses the generic server-side source contract and stays unavailable unless its URL, exact source notice, and `AMHARIC_BIBLE_LICENSE_CONFIRMED=true` are supplied. Before serving any text, it requires an `operation=books` response matching all 66 local books and exact chapter counts. API.Bible is the separate NIV adapter. It reads `NIV_BIBLE_API_KEY` and the exact account-provided `NIV_BIBLE_ID` server-side, checks that API.Bible returns an NIV edition with copyright metadata and a complete matching 66-book catalog, and requires `NIV_BIBLE_LICENSE_CONFIRMED=true`. Scripture requests use API.Bible's documented `api-key` header, JSON content response, and FUMS v3; copyright text comes from the provider's metadata/response. Confirm the selected Bible is licensed for this app and plan before setting the confirmation flag. Neither translation's text is stored in this repository.
