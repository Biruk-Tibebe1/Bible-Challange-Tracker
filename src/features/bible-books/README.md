# Bible Books

`bible-data.ts` is the framework-independent structural source of truth for the standard Protestant Bible. It defines all 66 books in canonical order and generates chapter references with a continuous global chapter number.

Use its lookup and range utilities for book/chapter access. `validateBibleDataset()` checks the catalog counts, ordering, unique IDs and chapter numbers, continuity, and required global-number examples. This feature does not depend on challenge dates, schedules, users, persistence, or Bible text.

Amharic and NIV Scripture use the same server-side external-source adapter; neither translation's text is stored in this repository. Configure the matching `*_BIBLE_API_URL` and exact provider-supplied `*_BIBLE_ATTRIBUTION` before the adapter returns content. `AMHARIC_BIBLE_API_KEY` is optional; `NIV_BIBLE_API_KEY` is required. Keys are server-only. The endpoint contract uses `operation=chapter|verse|search` with `bookId`, `chapterNumber`, `verseNumber`, `q`, `limit`, and `offset` query parameters. Chapter responses contain `verses` with `verseNumber` and `text`; verse responses contain `verseNumber` and `text`; search responses contain `results` with `bookId`, `chapterNumber`, `verseNumber`, and `text` or `snippet`. The adapter sends optional bearer authentication and reports unsupported operations explicitly. Verify each translation's own usage rights and required notice before configuring it.
